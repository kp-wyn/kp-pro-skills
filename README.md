## 🚀 Quick Start
## 快速开始

### kp-remember (记一下)

**English:**
Just say "remember this: ..." and it will be saved as-is to your designated folder.
No summarizing, no rewriting, no processing — just pure storage.

**中文：**
直接说"记一下：xxx"，内容会原样存入指定文件夹。
不总结、不改写、不加工——纯记录。

**Storage structure / 存储结构:**
```
KP-ST-library/
└── Project Name/
    └── 2026/
        └── 09/
            ├── record_0730_20260920.txt
            └── attachment.pdf
```

---

### kp-sum-trip-plan (工作总结计划)

**English:**
Say "make this week's summary plan" and it reads all your records, categorizes them, and outputs a beautiful HTML page + PDF version ready to share.

**中文：**
直接说"做个本周工作总结计划"，它会读取所有记录、自动分类，输出精美的HTML页面+PDF版本，可直接对外发送。

**Output / 输出:**
- `summary_projectname_20260920.html` — Visual web version
- `summary_projectname_20260920.pdf` — Shareable PDF version

## 📁 Installation
## 安装方法

### Step 1: Download
Download the ZIP file.

### Step 2: Extract
Unzip and you'll see two folders:
- `kp-remember/`
- `kp-sum-trip-plan/`

### Step 3: Install
Copy both folders into your `.user_skills/` directory.

That's it! Restart your AI and they're ready to use.
